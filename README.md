# TRIVAL — Thematic Review with Inbuilt Validation

A two-stage decision support framework for computational literature review.

- **Stage 1** identifies contextual themes from an article corpus using BERTopic (BAAI/bge-small-en embeddings + UMAP + HDBSCAN + cTF-IDF), with topic names generated by Claude (default Sonnet).
- **Stage 2** validates the themes through a multi-LLM ensemble: BART (NLI), SBERT (cosine similarity), and Gemini 2.5 Flash (LLM-as-judge), aggregated by majority voting.

Originally built for the CAHM (complementary and alternative healthcare management) corpus (694 abstracts, 45 years, Scopus). Framework is domain-agnostic — swap the input CSV to run on any corpus.

## Getting started

```bash
# Create virtual environment
python3.11 -m venv .venv
source .venv/bin/activate

# Install
pip install -r requirements.txt
pip install -e .

# One-time spaCy model download (for optional country extraction)
python -m spacy download en_core_web_sm

# Configure API keys
cp .env.example .env
# Edit .env and add ANTHROPIC_API_KEY, GEMINI_API_KEY
# Optional: TRIVAL_CLAUDE_MODEL=claude-opus-5-5 switches Stage 1 naming from Sonnet to Opus
```

## Opening in Cursor

1. Open the `paper2code` folder. Cursor will offer the recommended extensions from
   `.vscode/extensions.json` (Python, Cursor Pyright, Ruff, Jupyter); install them.
2. Select the interpreter: Command Palette, "Python: Select Interpreter", pick `.venv`.
3. Project rules for Cursor's AI are in `.cursorrules`.

## Running the pipeline

```bash
# Stage 1: BERTopic clustering + Claude topic naming
trival-stage1 --input data/raw/your_corpus.csv --out data/output/stage1_results.xlsx

# Stage 2: theme validation (full corpus, 3-voice ensemble)
trival-stage2-themes \
    --input data/raw/your_corpus.csv \
    --themes data/output/stage1_results.xlsx \
    --out data/output/stage2_theme_validation.xlsx

# Stage 2: method classification (qualitative / quantitative / mixed)
trival-stage2-methods \
    --input data/raw/your_corpus.csv \
    --out data/output/stage2_method_classification.xlsx

# Optional: country mentions via spaCy NER
trival-countries --input data/raw/your_corpus.csv --out data/output/abstracts_with_countries.csv
```

## Reference: original Colab notebooks

The three notebooks this package was refactored from are preserved in `notebooks/archive/`:

- `TRIVALStage1.ipynb` — BERTopic + LLaMA2 topic naming (Colab, GPU)
- `TRIVALStage2.ipynb` — illustrative Stage 2 (2 hardcoded abstracts)
- `TRIVALStage2_996Article.ipynb` — full-corpus BART+SBERT method classification

The refactored code reproduces the pipeline with these differences:
- Topic naming moved from local LLaMA2-13B (quantized) to Claude API (default Sonnet)
- Gemini 2.5 Flash added as a third voice in the Stage 2 ensemble (via the `google-genai` SDK)
- All I/O goes through typed functions in `trival.io`
- Hyperparameters and model IDs centralized in `trival.config`
